# СВОБОДА — Финансовая игра

## Быстрый старт

### 1. Скопируй файлы в проект

Скопируй всё содержимое этого архива поверх папки `swoboda-react`:
```
cp -r patch/* swoboda-react/
```

Или вручную перенеси каждую папку.

### 2. Создай таблицы в Supabase

Открой `supabase.com` → твой проект → SQL Editor → вставь содержимое `supabase-schema.sql` → Run.

### 3. Настрой переменные окружения

Скопируй `.env.local` в корень проекта `swoboda-react/`.
Замени `your_anthropic_api_key_here` на реальный ключ с `console.anthropic.com`.

### 4. Запусти

```bash
cd swoboda-react
npm install
npm run dev
```

Открой `localhost:3000/lobby`

## Структура

```
app/
  lobby/           → Создать/присоединиться к игре
  game/[roomId]/   → Игровой стол (лента + баланс + игроки + журнал)
  game/[roomId]/victory/  → Экран победы
  game/[roomId]/result/   → ИИ-разбор
  api/ai-report/   → API для генерации разбора

lib/
  supabase.ts      → Клиент Supabase
  gameEngine.ts    → Механика игры (ходы, покупки, боты)
  gameData.ts      → Данные (профессии, активы, мечты, клетки)

types/
  database.ts      → TypeScript типы
```

## Как играть

1. Открой `/lobby`
2. Введи имя → Создать игру
3. Поделись кодом комнаты с друзьями
4. Начни игру
5. Бросай кубик → принимай решения → строй пассивный доход
6. Когда пассив > расходы → выходишь на скоростную дорожку → получаешь ИИ-разбор
